Coding bursts, 2013–2026

About this chart

Across 12 personal hobby projects (professional/course work and tiny ones excluded), each gap-clustered burst of real activity — not each whole project — is its own row (a 120-day idle gap splits one; a single-day blip of 1–3 commits is dropped as noise, not drawn). Commits/day jumps roughly 2–4× exactly where Claude Code agentic commit attribution appears (bwv2, mundial, gear) — most visibly in bwv, where a tiny 2022 scaffold (bwv1, 23 commits, 22 LOC, 0% AI-attributed) and a 2025 rewrite (bwv2, 662 commits, 13,026 LOC) sit three years apart in the same repo but are, in every way that matters here, two different projects.

Reading this honestly: a burst's LOC is NOT a current snapshot — it's that project's LOC (cloc, excluding SVG/JSON/YAML/CSV/XML, plus manually-excluded vendor libraries and generated/data-dump files) as of the end of that specific burst, computed by checking out each contributing repo's last commit at or before the burst's end date. AI-attribution % is measured per burst (each burst's own commit range, not a project-wide blend) with chaoss/disclosure (committer emails, co-author trailers, tool mentions for Claude Code, Cursor, Copilot, ChatGPT, Aider) — it only catches disclosed, git-level traces, so chat-based AI use with no trailer or tool mention left in the repo (manually typed or pasted) is invisible to it, and true involvement may be higher than shown, especially before mid-2025.
