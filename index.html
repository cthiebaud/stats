Coding bursts, 2013–2026

About this chart

Across 14 personal hobby projects (professional/course work and tiny ones excluded), each gap-clustered burst of real activity — not each whole project — is its own row (commit history is clustered at two gap thresholds, 120 days then 45, so a few isolated bridge commits can't glue two genuinely separate episodes into one; a cluster touching only one working day is dropped as noise, not drawn). The y-axis is net new lines of code per working day — added minus deleted, so rework within the same burst cancels out, divided by the number of distinct days actually worked, not commit frequency, which is a workflow habit orthogonal to output. The three bursts with disclosed Claude Code agentic commit attribution (mundial 681/day, bwv2 524/day, gear 493/day) sit in the upper tier of this whole 13-year history — but don't own the top spot: the single highest burst by this measure is covid2 (Dec 2020–Jan 2021, 740/day), entirely hand-coded, predating any AI tool. Most visibly in bwv, where a tiny 2022 scaffold (bwv1, 23 commits, 4 net lines/day, 0% AI-attributed) and a 2025 rewrite (bwv2, 662 commits, 524 net lines/day) sit three years apart in the same repo but are, in every way that matters here, two different projects.

Reading this honestly: net lines/day is a proxy for "output that stuck within the burst," not value — it also nets out genuine cleanup of code that predates the burst (not just same-burst rework), and lines of code is a weak stand-in for what actually mattered, a limitation no git-only metric fixes. A burst's LOC circle is NOT a current snapshot — it's that project's LOC (cloc, excluding SVG/JSON/YAML/CSV/XML, plus manually-excluded vendor libraries and generated/data-dump files) as of the end of that specific burst, computed by checking out each contributing repo's last commit at or before the burst's end date. AI-attribution % is measured per burst (each burst's own commit range, not a project-wide blend) with chaoss/disclosure (committer emails, co-author trailers, tool mentions for Claude Code, Cursor, Copilot, ChatGPT, Aider) — it only catches disclosed, git-level traces, so chat-based AI use with no trailer or tool mention left in the repo (manually typed or pasted) is invisible to it, and true involvement may be higher than shown, especially before mid-2025.
